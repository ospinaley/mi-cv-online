Temario básico de HTML

Propuesta de contenidos para un módulo inicial: cada bloque termina con un ejercicio práctico en el editor.

1Tu primer archivo

  • Instalar y configurar VS Code
  • Crear index.html y abrirlo en el navegador
  • Guardar y recargar: el ciclo de trabajo

2Etiquetas y atributos

  • Etiquetas de apertura, cierre y vacías
  • Atributos: href, src, alt, class
  • Títulos, párrafos, listas, enlaces e imágenes

3Partes del documento

  • <!DOCTYPE html>, html, head, body
  • Qué va en el head: meta, title, enlaces
  • Comentarios e indentación

4El DOM

  • El navegador convierte el HTML en un árbol
  • Padres, hijos y hermanos
  • Inspeccionar una página con las herramientas del navegador

5Estructura general

  • HTML semántico: header, nav, main, section, footer
  • Buenas prácticas y accesibilidad básica
